# 7 Months, 1000 Stories ❤️

A single-page interactive website built from the provided reference designs.

## Structure
- Our Story: 10 numbered sections
- Game Zone: 10 numbered sections
- Boyfriend's Day Special: 8 sections
- Memory Wall uses the 8 uploaded illustrations supplied for this project.

## Run locally
1. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
2. Open `index.html` in a browser.

For the best local experience, use VS Code + Live Server, or any simple static web server.

## Share publicly
Upload the folder to a static hosting service such as Vercel, Netlify, or GitHub Pages. The website is frontend-only, so no backend is required.

## Personalization
Edit the text/questions inside `script.js`. Replace images in `assets/` if you later want different memory illustrations.
